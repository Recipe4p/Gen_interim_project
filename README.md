# Weather Pipeline

Singapore is a small island. A little red dot you might say and consistently hot and humid. One would expect the distant from the east to the west to be small enough that there is no diffference in the weather metrics, but is it really. In this project, we set to explore and find out if there is a diiference and where is the region with the best weather metric in Singapore.

## Data source

Following weather metrics from NEA were chosen for this exploration:
1)wind
2)rainfall
3)Pm 2.5
4) WBGT
